# V8 — Professional profile card
The `/contact` page includes a CEO-style professional contact profile for Mr. KEAT LENARITH, with a neutral illustration placeholder (not a photograph of the person), institution affiliations, email and phone links, and English/Khmer text.

## Replace photo
1. Open `/contact`.
2. Click **Visual edit (local)**.
3. Click the large profile image and choose your JPG/PNG file (less than 1.5 MB in the current browser-local CMS).
4. Click **Finish editing**, then open **CMS dashboard** and publish changes.

This CMS stores image data in browser localStorage; changes do not propagate to other visitors or devices. For production, use authenticated CMS and object storage. The form on the contact page remains a demo and does not send messages.
