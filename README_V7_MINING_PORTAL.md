# GeoCam V7 — Cambodia Mining Information Portal

- New `/mining` page, linked in header, mobile navigation, footer and homepage feature cards.
- 13 bilingual records: six license types, four geological resources, legislation, laboratory and administrative services.
- Keyword search, category filters, expandable requirements and per-record official MME source links.
- Independent educational summaries; not an official government licensing service.
- Descriptions and figures are summaries of publicly described MME pages from the previous extraction; verify current legal texts and fees at the official source.
- CMS `data-cms-id` anchors are present on portal title, introduction and record text. Existing CMS remains local browser storage.
- No legal PDF content or GIS datasets are included; these would require separate extraction and rights review.
- Existing GeoData, 3D Geopark, Lexicon, bilingual switch and site styling are preserved.

Run `npm install` then `npm run dev`; visit `/mining`.
