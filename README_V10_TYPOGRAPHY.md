# GeoCam V10 — Typography and Khmer accessibility

- English: Times New Roman (Times/Georgia fallback).
- Khmer: Google Sans Khmer when installed/available, otherwise Noto Sans Khmer from Google Fonts, then Khmer OS Siemreap.
- The website switches CSS according to the existing `html lang` attribute controlled by the language selector.
- Khmer root font: 18 px desktop, 17 px mobile, line height 1.85–1.9. Headings and CTA sizes adapted for Khmer glyph proportions.
- Applies across all website routes including GeoData, Geopark, Mining, Lexicon and CMS interface where rendered in the same document.
- Google Sans Khmer is not bundled; if licensed font files are available, install and configure them separately. Do not redistribute proprietary font files.
- Test long Khmer headings and interactive map labels on actual mobile devices.
